## 설명

```
Consultez votre prochain cours sans sortir votre téléphone.

Ouvrez l'application : elle affiche le cours qui compte maintenant.
NOW si un cours a lieu en ce moment, NEXT s'il n'a pas encore commencé.
Haut/bas pour passer d'un cours à l'autre, START pour revenir au présent.

Un aperçu (glance) est inclus. Vous voyez votre prochain cours en faisant
défiler le cadran, sans ouvrir l'application.


■ Saisir votre emploi du temps

Application Garmin Connect → réglages de cette application, un champ par jour
(les 7 jours).

Séparez les cours par un point-virgule (;).

  09:00-09:50,Systèmes exploitation,T0503;10:00-11:50,Bases données,B201

  → 09:00-09:50  Systèmes exploitation  T0503
    10:00-11:50  Bases données          B201

Chaque cours s'écrit [horaire],[nom],[salle], séparés par des virgules.
La salle est facultative.

  13:00-14:50,Étude

Le format horaire est souple. Ces écritures sont équivalentes :

  09:00   9:00   0900

Vous pouvez utiliser '~' au lieu de '-'. Les espaces en trop sont ignorés.
Les cours sont triés par heure de début : l'ordre de saisie n'a pas d'importance.

Laissez un jour vide si vous n'avez pas cours.


■ Noms de cours longs

Les noms longs passent sur deux lignes. La coupure se fait à une espace :

  Systèmes exploitation  →  Systèmes
                            exploitation

Sans espace, le nom est coupé en son milieu : ajoutez-en une à l'endroit
le plus lisible.


■ Remarques

· Pour écrire les noms de cours dans une langue donnée, la montre doit être
  réglée sur cette langue (Paramètres → Système → Langue). Les applications
  Connect IQ utilisent les polices de la montre.
· Les cours à cheval sur minuit ne sont pas pris en charge.
· Certains appareils ne gèrent pas les aperçus. L'application elle-même
  y fonctionne normalement.
```

## 업데이트 내역 (What's New)

### 1.0.3

```
· Six langues de plus : japonais, français, allemand, espagnol, italien et
  polonais — neuf au total
· Les montres réglées sur une autre langue basculent désormais sur l'anglais.
  Elles recevaient auparavant du texte coréen, qui s'affichait en carrés ou en
  points d'interrogation
· « Pas de cours » et « Journée finie » s'affichaient en coréen sur toutes les
  montres. Ces textes sont maintenant traduits
· Les jours écrits dans votre langue sont acceptés quand vous collez un emploi
  du temps — 周一, Lun, Mo, 月, Pon, etc.
· L'exemple chinois dans les réglages montrait un jour que l'application ne
  savait pas lire. Corrigé
```

### 1.0.1

```
· Bien plus d'appareils pris en charge — 107 au total, dont Forerunner, Venu,
  vívoactive et fenix
· Saisie de l'emploi du temps plus tolérante. Les sauts de ligne et les
  marqueurs de jour comme « Mon: » sont désormais acceptés
· Un message « Format incorrect » clair lorsque l'emploi du temps ne peut pas
  être lu. Auparavant, seul « Pas de cours » s'affichait
· Les horaires ne sont plus tronqués dans l'aperçu
· Texte plus grand sur les écrans carrés comme le Venu Sq
```
