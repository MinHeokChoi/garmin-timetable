# 시간표 입력 도구 — 계획

친구가 자기 시간표를 스스로 넣게 만드는 것이 목표다.
지금은 형식을 설명으로만 알려주는데, 그걸 화면으로 대체한다.

## 만들 것

정적 웹 페이지 하나. GitHub Pages 무료 호스팅. 서버 없음.

앱 설정 화면(Garmin Connect)에서 이 페이지로 가는 링크를 띄운다.
설정 스키마의 `helpUrl` 속성이 그 역할을 한다.

## 입력 경로 세 가지, 출력은 하나

```
  표에 직접 입력  ┐
  이미지 → 챗봇  ├→  편집 화면(표)  →  요일별 문자열 5개 + 복사 버튼
  기존 설정 불러오기 ┘
```

**편집 화면이 중심이다.** 어느 경로로 들어와도 표에서 눈으로 확인하고 고친 다음
내보낸다. 검증을 건너뛰는 경로는 두지 않는다 — 인식이 틀린 걸 모르고 넣으면
수업을 놓친다.

### 1. 직접 입력
요일 × 수업 표. 시간·과목명·강의실을 채운다.

### 2. 이미지 → 챗봇
`이미지에서 가져오기` 버튼을 누르면 **완성된 프롬프트**가 나온다.
친구는 그걸 복사해서 자기가 쓰는 챗봇에 시간표 사진과 함께 넣고,
결과를 다시 페이지에 붙여넣는다. 페이지가 파싱해서 표를 채운다.

서버를 안 쓰는 이유는 [아래](#왜-서버를-안-쓰나) 참고.

### 3. 기존 설정 불러오기
이미 넣어둔 문자열을 붙여넣으면 표로 되돌린다.
**학기 중에 강의실 하나 바뀔 때 이게 없으면 처음부터 다시 짜야 한다.**

## 프롬프트가 실질적인 산출물이다

인식 품질은 프롬프트가 결정한다. 여기 들어가야 할 것:

- 출력 형식 명세와 예시 두어 개
- **다른 말 붙이지 말고 다섯 줄만 내라**는 지시
- 병합된 셀(2~3교시 연강)을 한 항목으로 합치라는 규칙
- 안 읽히는 칸은 **추측하지 말고 표시하라**는 지시
- 주말·공강은 빈 줄로

## 형식은 지금 것을 고정한다

```
09:00-09:50,운영체제,T0503;10:00-11:50,데이터베이스,B201
```

**페이지와 시계가 같은 규칙을 써야 한다.** 페이지 쪽 검증기는 앱 파서와 같은
규칙을 구현한다 — 시간 표기 정규화, 종료가 시작보다 빠르면 거부, 시간순 정렬.
한쪽만 고치면 "페이지에선 되는데 시계에선 안 되는" 상황이 생긴다.

## 한글은 우리 강점이다

같은 일을 하는 기존 앱(School Timetable)은 "시계가 비라틴 문자를 지원하지
않으니 영어로 적으라"고 안내한다. 폰트 문제를 못 풀고 포기한 것이다.

우리는 시계 언어가 한국어면 한글이 나온다는 걸 확인했다. 페이지에 그 조건을
안내하고, 한글 그대로 쓰게 한다.

## 순서

**1. 앱에 링크 자리를 먼저 박는다 — Store 제출 전에.**

GitHub Pages 주소는 저장소 이름만 정하면 미리 알 수 있다
(`https://<계정>.github.io/<저장소>/`). 페이지가 아직 없어도 주소는 확정할 수 있다.

이걸 지금 안 넣으면 **첫 배포판에는 링크가 없다.** 나중에 넣으려면 앱을 다시
올리고 심사를 다시 받아야 한다. 심사 기간에 페이지를 만들면 승인 시점에 맞는다.

**2. 편집 화면** — 표 입력, 내보내기, 되불러오기

**3. 이미지 프롬프트 경로**

**4. (조건부) 서버** — 3번을 실제로 써 보고 챗봇 왕복이 정말 거슬릴 때만

## 왜 서버를 안 쓰나

맥미니로 처리하자는 안이 있었는데, 비용이 이득보다 크다.

- 정적 페이지(HTTPS)가 집 컴퓨터를 부르려면 터널·도메인·인증서가 필요하고,
  **맥미니가 24시간 켜져 있어야 한다.** 유지보수 없는 페이지가 운영해야 하는
  서비스로 바뀐다
- 친구 한 명이 쓰는 건 **학기당 한 번**이다. 상시 서버를 정당화하지 못한다
- 친구들 시간표 이미지가 집 컴퓨터로 들어온다
- **어차피 검증 화면은 필요하다.** 서버를 세워도 표는 만들어야 한다

체감 차이는 "사진 올리기" 대신 "프롬프트 복사 → 챗봇에 사진과 붙여넣기" 한 단계다.
써 보고 이게 정말 걸리면 그때 붙인다. 그때는 Tailscale Funnel 이 제일 현실적이다.

## 정해야 할 것

**저장소 이름** — GitHub Pages 주소가 여기서 나온다. 앱에 박아야 하니 먼저 정한다.

**토요일 수업** — 앱이 지금 월~금만 지원한다. 토요일 수업이 있는 친구가 있으면
설정 칸과 앱 로직을 하나씩 늘려야 한다. 필요한지 먼저 확인.

**과목명 길이** — 시계 화면이 좁아 긴 이름은 두 줄로 접히거나 요약에서 잘린다.
페이지에서 미리 경고할지, 짧은 표시용 이름을 따로 받을지.
