# 중국어판 요청 답장 (llin568@qq.com)

Connect IQ 앱 관리자 메일에 그대로 답장하거나 위 주소로 보내면 된다.

## 보낼 내용

```
Hi,

Thanks for asking — Simplified Chinese is now supported.

The update (1.0.1) is submitted and will appear in the Connect IQ Store after
Garmin's review. Once you update the app, set your watch language to Chinese
and the app will be in Chinese.

One thing worth knowing: Connect IQ apps use the watch's own fonts, so Chinese
class names only render when the watch language is set to Chinese
(Settings > System > Language). With any other language they show as boxes.

To enter your timetable there is a small web page that builds the settings
string for you — you can also just take a photo of your timetable, and it
gives you a prompt to paste into any AI chatbot:

  https://minheokchoi.github.io/garmin-timetable/

The app also shows a QR code for that page: open the app with no timetable
set and press DOWN.

Let me know if anything reads wrong in Chinese — I don't speak it, so
corrections are welcome.

Best,
Minick
```

## 중국어를 곁들이고 싶으면 이 문단을 앞에 붙인다

```
你好，

感谢反馈。简体中文已经支持了，更新版本（1.0.1）已提交审核。
更新后请将手表语言设为中文，应用界面就会显示中文。

请注意：Connect IQ 应用使用手表自带的字体，因此课程名要显示中文，
手表语言必须设为中文（设置 → 系统 → 语言），否则会显示为方块。

输入课表可以使用这个网页，拍一张课表照片即可：
https://minheokchoi.github.io/garmin-timetable/
```

## 참고

- 번역이 어색한 부분을 지적해 달라고 열어 둔 문장이 마지막에 있다.
  중국어를 모르는 상태로 낸 것이니 실제 사용자 피드백이 가장 정확하다.
- 요청자 기기는 Forerunner 265 (round-416x416) 로 이미 지원 목록에 있다.
