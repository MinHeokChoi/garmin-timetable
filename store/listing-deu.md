```
Next Class
```

## 한 줄 소개
```
Aktueller und nächster Kurs direkt am Handgelenk
```

## 설명

```
Sieh nach deinem nächsten Kurs, ohne zum Handy zu greifen.

Öffne die App: Sie zeigt den Kurs, auf den es gerade ankommt.
NOW, wenn einer läuft, NEXT, wenn er noch nicht begonnen hat.
Hoch/runter wechselt zwischen den Kursen, START springt zurück in die Gegenwart.

Eine Glance-Ansicht ist dabei. Du siehst deinen nächsten Kurs schon beim
Durchblättern des Watchface, ganz ohne die App zu öffnen.


■ Stundenplan eingeben

Garmin Connect App → Einstellungen dieser App, ein Feld pro Tag (alle 7 Tage).

Trenne die Kurse mit einem Semikolon (;).

  09:00-09:50,Betriebssysteme,T0503;10:00-11:50,Datenbanken,B201

  → 09:00-09:50  Betriebssysteme  T0503
    10:00-11:50  Datenbanken      B201

Jeder Kurs ist [Zeit],[Name],[Raum], durch Kommas getrennt.
Der Raum ist optional.

  13:00-14:50,Lernzeit

Das Zeitformat ist flexibel. Diese Schreibweisen bedeuten dasselbe:

  09:00   9:00   0900

Statt '-' geht auch '~'. Zusätzliche Leerzeichen werden ignoriert.
Sortiert wird nach Beginn — die Reihenfolge der Eingabe spielt keine Rolle.

Lass einen Tag leer, wenn du keine Kurse hast.


■ Lange Kursnamen

Lange Namen werden auf zwei Zeilen umgebrochen, und zwar an einem Leerzeichen:

  Betriebssysteme Praktikum  →  Betriebssysteme
                                Praktikum

Ohne Leerzeichen wird in der Mitte getrennt — setze also eines dort,
wo es sich am besten liest.


■ Hinweise

· Damit Kursnamen in einer bestimmten Sprache erscheinen, muss die Uhr auf
  diese Sprache eingestellt sein (Einstellungen → System → Sprache).
  Connect IQ Apps verwenden die Schriftarten der Uhr.
· Kurse über Mitternacht hinaus werden nicht unterstützt.
· Manche Geräte unterstützen keine Glances. Die App selbst läuft dort normal.
```

## 업데이트 내역 (What's New)

### 1.0.3

```
· Sechs weitere Sprachen: Japanisch, Französisch, Deutsch, Spanisch,
  Italienisch und Polnisch — insgesamt neun
· Uhren mit einer anderen Sprache greifen jetzt auf Englisch zurück. Vorher
  bekamen sie koreanischen Text, der als Kästchen oder Fragezeichen erschien
· „Heute frei" und „Heute fertig" wurden auf jeder Uhr auf Koreanisch
  angezeigt. Sie sind jetzt übersetzt
· Beim Einfügen des Stundenplans werden Tagesangaben in deiner Sprache
  erkannt — 周一, Lun, Mo, 月, Pon und weitere
· Der chinesische Hinweis in den Einstellungen zeigte eine Tagesangabe, die
  die App nicht lesen konnte. Behoben
```

### 1.0.1

```
· Deutlich mehr Geräte unterstützt — insgesamt 107, darunter Forerunner, Venu,
  vívoactive und fenix
· Nachsichtigere Stundenplan-Eingabe. Zeilenumbrüche und Tagesangaben wie
  „Mon:" werden jetzt akzeptiert
· Klare Meldung „Format prüfen", wenn der Stundenplan nicht lesbar ist.
  Vorher stand dort nur „Heute frei"
· Kurszeiten werden in der Glance-Ansicht nicht mehr abgeschnitten
· Größere Schrift auf eckigen Displays wie der Venu Sq
```
