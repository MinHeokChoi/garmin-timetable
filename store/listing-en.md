# Connect IQ Store listing (English)

## App name
```
Timetable
```

## Tagline
```
See your current and next class right on your wrist
```

## Description

```
Check your next class without reaching for your phone.

Open the app and it shows the class that matters right now.
NOW if one is in progress, NEXT if it has not started yet.
Use up/down to move between classes, START to jump back to the present.

A glance is included. You can see your next class by scrolling the
watch face, without opening the app at all.


■ Entering your timetable

Garmin Connect app -> this app's settings, one field per day (all 7 days).

Separate classes with a semicolon (;).

  09:00-09:50,Operating Systems,T0503;10:00-11:50,Databases,B201

  -> 09:00-09:50  Operating Systems  T0503
    10:00-11:50  Databases          B201

Each class is [time],[name],[room], separated by commas.
The room is optional.

  13:00-14:50,Study hall

Time format is flexible. These all mean the same thing:

  09:00   9:00   0900

You can use '~' instead of '-'. Extra spaces are ignored.
Entries are sorted by start time, so the order you type does not matter.

Leave a day empty if you have no classes.


■ Long class names

Long names fold onto two lines. The split happens at a space:

  Operating Systems  ->  Operating
                         Systems

Without a space the name is split in the middle, so add one where it reads best.


■ Notes

· To use non-Latin class names, the watch language must be set to that
  language (Settings -> System -> Language). Connect IQ apps use the
  watch's own fonts.
· Classes crossing midnight are not supported.
· vívoactive 4 / Venu / Venu (Mercedes-Benz) do not support glances.
  The app itself works normally on them.
```

## Buttons
```
Up     previous class
Down   next class
START  back to now
BACK   exit
```
