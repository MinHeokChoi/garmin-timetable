# Connect IQ Store 등록 문안 (중국어 간체)

## 앱 이름
```
Next Class
```

## 한 줄 소개
```
在手腕上直接查看当前和下一节课
```

## 설명

```
不用掏出手机，抬手就能看到下一节课。

打开应用，它会显示此刻最相关的那节课。
正在上课时显示 NOW，还没开始时显示 NEXT。
用上下键翻看前后的课，按 START 回到当前时刻。

还支持概览（Glance）。不打开应用，在表盘上滑动就能看到下一节课。


■ 输入课表

Garmin Connect 应用 → 本应用的设置，每天一栏，周一到周日共七天。

课与课之间用分号(;)分隔。

  09:00-09:50,高等数学,A101;10:00-11:50,大学物理,B201

  → 09:00-09:50  高等数学  A101
    10:00-11:50  大学物理  B201

每节课的顺序是 [时间],[课程名],[教室]，用逗号分隔。教室可以省略。

  13:00-14:50,自习

时间格式很宽松，下面几种写法意思相同。

  09:00   9:00   0900

也可以用 '~' 代替 '-'，前后的空格会自动清理。
即使输入顺序颠倒，也会按开始时间排好。

没有课的那天留空即可。


■ 课程名较长时

超过 8 个字的名称会在屏幕上分成两行显示。
分行的位置由空格决定。

  高等数学 微积分  →  高等数学
                     微积分

没有空格时会从中间断开。觉得别扭就在合适的位置加一个空格。


■ 说明

· 课程名要用中文的话，手表语言也需要设为中文。
  （设置 → 系统 → 语言）其他语言下中文会显示为方块。
· 不支持跨过午夜的日程。
· 部分机型不支持概览（Glance）画面，应用本身可正常使用。
```

## 업데이트 내역 (What's New)

### 1.0.1

```
· 大幅增加支持的机型，共 107 款，包括 Forerunner、Venu、vívoactive、fenix
· 粘贴课表时对格式更宽容。换行或 "周一:" 这样的星期标记也能识别
· 无法识别课表时会显示"格式有误"。以前只显示"今天没有课"，看不出问题在哪
· 概览画面中上课时间不再被截断
· 在 Venu Sq 等方形屏幕的机型上文字更大
```

## 버튼 안내
```
上     上一节课
下     下一节课
START  回到当前时刻
BACK   退出
```
