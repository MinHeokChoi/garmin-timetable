# Connect IQ Store 등록 문안 (한국어)

## 앱 이름
```
Next Class
```

## 한 줄 소개
```
손목에서 지금·다음 수업을 바로 확인하는 시간표 앱
```

## 설명

```
수업 사이에 스마트폰을 꺼내지 않고, 손목에서 바로 다음 수업을 확인합니다.

앱을 열면 지금 시각을 기준으로 가장 관련 있는 수업을 보여줍니다.
진행 중이면 NOW, 아직이면 NEXT 입니다.
위/아래 버튼으로 앞뒤 수업을 넘겨보고, START 로 현재 시각으로 돌아옵니다.

요약(Glance) 화면도 지원합니다. 앱을 열지 않고 시계 화면에서
위아래로 넘기기만 해도 다음 수업이 보입니다.


■ 시간표 넣기

Garmin Connect 앱 → 이 앱의 설정에서 요일별로 입력합니다. 월~일 7일 모두 있습니다.

한 줄에 한 요일을 넣고, 수업은 세미콜론(;)으로 구분합니다.

  09:00-09:50,운영체제,T0503;10:00-11:50,데이터베이스,B201

  → 09:00-09:50  운영체제   T0503
    10:00-11:50  데이터베이스 B201

각 수업은 [시간],[이름],[강의실] 순서이고 쉼표로 구분합니다.
강의실은 생략해도 됩니다.

  13:00-14:50,자율학습

시간 형식은 자유롭습니다. 아래가 전부 같은 뜻입니다.

  09:00   9:00   0900

'-' 대신 '~' 를 써도 되고, 앞뒤 공백은 알아서 정리됩니다.
입력 순서가 뒤바뀌어도 시간순으로 정렬해서 보여줍니다.

수업이 없는 요일은 비워 두면 됩니다.


■ 긴 과목명

8자가 넘는 이름은 화면에서 두 줄로 나뉩니다.
나뉘는 자리는 띄어쓰기로 정합니다.

  데이터베이스 시스템  →  데이터베이스
                        시스템

띄어쓰기가 없으면 글자 수 절반에서 나뉩니다. 어색하면 끊기면 좋을
자리에 공백을 하나 넣으세요.


■ 참고

· 과목명을 한글로 넣으려면 시계 언어가 한국어여야 합니다.
  (설정 → 시스템 → 언어) 다른 언어에서는 한글이 표시되지 않습니다.
· 자정을 넘기는 일정은 지원하지 않습니다.
· 일부 기기는 요약(Glance) 화면을 지원하지 않습니다. 앱 자체는 정상 동작합니다.
```

## 버튼 안내
```
위    이전 수업
아래   다음 수업
START 현재 시각으로
BACK  종료
```
