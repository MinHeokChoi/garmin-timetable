# Connect IQ Store 등록 문안 (일본어)

## 앱 이름
```
Next Class
```

## 한 줄 소개
```
今の授業と次の授業を、手首でそのまま
```

## 설명

```
スマホを取り出さずに、次の授業を確認できます。

アプリを開くと、いま関係のある授業が出ます。
授業中なら NOW、まだ始まっていなければ NEXT。
上下で授業を行き来し、START で現在時刻に戻ります。

概要（Glance）にも対応しています。ウォッチフェイスをスクロールするだけで、
アプリを開かずに次の授業が見られます。


■ 時間割の入力

Garmin Connect アプリ → このアプリの設定に、曜日ごとの入力欄が7日分あります。

授業どうしはセミコロン(;)で区切ります。

  09:00-09:50,オペレーティングシステム,T0503;10:00-11:50,データベース,B201

  → 09:00-09:50  オペレーティングシステム  T0503
    10:00-11:50  データベース              B201

1件は [時間],[科目名],[教室] をコンマで区切った形です。
教室は省略できます。

  13:00-14:50,自習

時刻の書き方は自由です。次はどれも同じ意味になります。

  09:00   9:00   0900

'-' の代わりに '~' も使えます。余分な空白は無視されます。
開始時刻の順に並べ替えられるので、入力の順番は気にしなくてかまいません。

授業がない曜日は空のままにしておきます。


■ 長い科目名

長い名前は2行に折り返されます。折り返す位置は半角スペースです。

  データベース システム  →  データベース
                            システム

スペースがないと真ん中で切れるので、読みやすい位置に1つ入れてください。


■ 注意

· 科目名をその言語で表示するには、時計の言語もその言語に設定してください
  （設定 → システム → 言語）。Connect IQ アプリは時計側のフォントを使います。
· 日付をまたぐ授業には対応していません。
· 一部の機種は概要に対応していません。その場合もアプリ本体は通常どおり動きます。
```

## 업데이트 내역 (What's New)

### 1.0.3

```
· 対応言語を6つ追加 — 日本語・フランス語・ドイツ語・スペイン語・イタリア語・
  ポーランド語。あわせて9言語になりました
· それ以外の言語に設定された時計は、英語で表示されるようになりました。以前は
  韓国語の文字が出て、四角や「?」になっていました
· 「今日は授業なし」「今日は終了」がどの時計でも韓国語で出ていたのを、
  各言語に翻訳しました
· 時間割を貼り付けるとき、自分の言語の曜日表記を読み取ります —
  周一、Lun、Mo、月、Pon など
· 設定の中国語の例が、アプリの読み取れない曜日表記になっていたのを直しました
```

### 1.0.1

```
· 対応機種を大幅に追加 — Forerunner、Venu、vívoactive、fenix など計107機種
· 時間割の貼り付けに対して寛容になりました。改行や「Mon:」のような曜日表記も
  読み取れます
· 時間割を読み取れないときに「形式を確認」と表示するようになりました。
  以前は「今日は授業なし」としか出ず、原因が分かりませんでした
· 概要画面で授業の時刻が途中で切れないようにしました
· Venu Sq などの四角い画面で文字を大きくしました
```

## 버튼 안내
```
上      前の授業
下      次の授業
START   現在時刻に戻る
BACK    終了
```
